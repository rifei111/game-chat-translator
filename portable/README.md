# Lingua Studio 便携版分卷

这是 `LinguaStudio-portable.zip` 的 7 个分卷，总大小约 409 MiB。

1. 下载本目录下全部 `LinguaStudio-portable.zip.001` 到 `.007`，以及 `assemble.bat`。
2. 把全部文件放在同一个目录，双击 `assemble.bat`。
3. 合并得到 `LinguaStudio-portable.zip`，再解压。
4. 解压后双击 `LinguaStudio.exe`；必须保留同目录的 `_internal`。

SHA256（合并后的 zip）：

注意：便携包未签名；Windows SmartScreen 若拦截，选择“更多信息 → 仍要运行”。首次语音识别会在应用内下载 Whisper base 模型（约 141 MB）。
