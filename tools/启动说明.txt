Lingua Studio 1.0 · Windows 便携版
====================================

1. 解压整个压缩包，得到一个 LinguaStudio 文件夹。
2. 双击里面的 LinguaStudio.exe。
   - 不要只把 exe 拖出来：它依赖同目录的 _internal 运行时。
3. 首次启动会创建 data 文件夹，配置、日志、模型都在里面。
4. 首次使用语音识别：
   打开「语音识别」页面 → 选择「系统声音 · VB-Cable」或你的麦克风
   → 点击「开始聆听」。如果提示模型待下载，点「检查模型」，
   base 模型约 141 MB，只从镜像下载一次，之后完全离线。
5. 屏幕识别：
   「屏幕识别」页面 → 截取屏幕并圈选 → 框住游戏聊天区域 → 应用区域。
   默认是演示模式，真实使用前把「演示模式」关掉。
6. 手机接力：
   手机和电脑连同一个 WiFi → 「手机接力」页面扫码。
   配对码固定为 514666，也可以在 data/config.json 改。
7. 字幕条：
   「实时字幕」或「外观与字幕」页面可以预览桌面置顶字幕条；
   它鼠标穿透、不会抢焦点。

系统要求
--------
- Windows 10/11 64 位。
- Microsoft Edge WebView2 Runtime（Windows 11 通常自带）。
  如果双击没有窗口，先安装：
  https://developer.microsoft.com/microsoft-edge/webview2/
- 首次语音模型下载需要网络；日常 OCR + 本地 Whisper 可离线运行。
- 在线翻译（免费引擎）需要网络；敏感场景请在「翻译引擎」切换到 Argos 离线。

已内置
------
- 8 个页面：概览 / 实时字幕 / 语音识别 / 屏幕识别 / 手机接力 / 翻译引擎 / 外观与字幕 / 关于
- 多语种屏幕 OCR（中/日/英/韩/俄/阿拉伯/欧洲语言）
- faster-whisper 本地语音转文字 + 翻译
- Win32 置顶字幕条（圆角玻璃、淡入滑入、鼠标穿透）
- 手机 PWA + 二维码 + 双向剪贴板
- Apple 风格界面：深空黑 / 晨光主题、粒子、鼠标光晕、磁吸按钮、3D 卡片、能量球波形

隐私
----
只截屏幕像素，不读游戏内存、不注入进程、不改游戏文件。
语音识别在本机完成，音频不上传。
