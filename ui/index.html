ABOUT

Lingua Studio

一间为跨语言游戏聊天而生的控制台。把 OCR、语种识别、翻译、语音转写与局域网字幕流，收进一个安静、顺滑的桌面应用。

Python 3.12WebView2RapidOCRfaster-whisperWebSocket
01本地优先

截屏 OCR、语种识别、语音转写均在本机完成。只有在线翻译会把当前文本发给服务商。

02屏幕只读

不读游戏内存、不注入进程、不改游戏文件，主流反作弊不会因此判定异常。

03局域网闭环

手机通过同一 WiFi 的中继接收字幕，配对码隔离，断开即失联，中继只转发不落库。
